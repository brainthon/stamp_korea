# 회원 등급 구조

- `member_memberships`는 회원 등급의 원본이다. 기존 회원과 신규 회원은 무료로 생성된다.
- `plan`: `free`, `premium`. 관리자 권한 `app_metadata.stamp_admin`과 독립적이다.
- `subscription_status`: `inactive`(미구독), `active`(구독 중), `canceled`(다음 갱신 해지), `expired`(만료).
- 프리미엄 권한은 `active` 또는 `canceled`이고 `period_start <= now() < period_end`인 경우에만 유효하다. 만료된 저장 레코드의 상태가 아직 `active`여도 조회 결과는 무료·만료로 반환된다. 자동 작업이 꺼져 있어도 권한이 유지되지 않는다.
- 회원 앱은 `get_my_membership()` 또는 `MembershipService.fetch()`로 자신의 권한만 조회한다. 네트워크 오류는 무료로 덮어쓰지 않고 호출자에게 전달된다.
- 일반 회원은 등급·기간·구독 상태를 변경할 수 없다. 관리자 목록은 `admin-members`의 실제 사용자 인증·관리자 확인 후 서버 전용 RPC로 조회한다.
- 관리자 회원관리에서 무료/프리미엄 필터는 현재 유효한 권한을 기준으로 한다. 상세 정보에 구독 상태와 시작·종료일이 표시된다.

## 결제 연동 시 추가할 작업

검증된 결제 통지 또는 앱스토어 구매 검증을 처리하는 서버만 이 테이블을 갱신한다. 결제 이벤트 중복 방지, 이벤트 순서 검증, 구매자 연결, 환불과 권한 회수, 결제 이력을 별도로 구현해야 한다. 갱신 시 `updated_at`도 기록한다. 클라이언트에서 전달한 등급이나 기간은 신뢰하지 않는다.

현재 결제, 유료 전환 버튼, 등급별 판독·사진 저장 한도, 광고 정책은 연동되지 않았다. 기존 판독 제한과 앱 기능은 유지된다. 실제 유료 기능은 서버에서 같은 기간 조건을 검증하도록 연결해야 하며 앱 화면의 등급만으로 허용하면 안 된다.
