# 사진 제공 및 판독 개선

- 자동 추출: 단색에 가까운 배경의 연결 영역을 제거하고 우표 주변을 자릅니다. 복잡한 배경·겹친 우표·원근 보정은 자동 지원하지 않습니다. 사용자가 미리보기를 확인한 후 적용합니다.
- 개인 수집 사진은 자동으로 제공/학습 데이터가 되지 않습니다.
- 비교 자료 제공과 추가 학습 동의는 모두 기본 해제입니다. 로그인 회원만 제공할 수 있습니다.
- 비공개 recognition-contributions 버킷, 1MB JPEG 제한, EXIF 재인코딩 제거. 소유자/관리자만 조회 가능.
- 관리자는 공식 원본과 비교해 승인/반려합니다. 승인된 사진만 공식 이미지에 보조적으로 추가되며 판독 당 최대 3장입니다.
- 관리자 권한은 auth.users.raw_app_meta_data.stamp_admin=true로 부여합니다. user_metadata는 권한에 사용하지 않습니다. 지정 관리자 계정의 권한은 앞선 작업에서 부여됐습니다. 신규 관리자 부여는 사용자 확인과 기존 메타데이터 보존이 필요하며 적용 후 토큰 갱신/재로그인이 필요합니다. 현재 검증 범위는 PROJECT_STATUS.md를 확인하세요.
- 제공 철회는 DB 레코드를 먼저 삭제하여 참조를 중단하고 저장 사진을 삭제합니다. 저장소 삭제 실패 시 운영자가 고아 파일을 정리해야 합니다.

## 추가 학습 상태

사진 축적/비교 활용은 모델 파라미터 학습과 다릅니다. scripts/export_training_dataset.py는 승인 + 추가 학습 동의된 사진만 내보냅니다. 원본 제공자 단위로 학습/검증을 나누고 동일 파일 중복을 제거합니다. 실행 시 빈 출력 디렉터리가 필요합니다. 서비스 역할 키는 서버/관리자 환경에서만 사용합니다.

아직 검수된 학습 자료와 평가 세트가 없으므로 추가 모델 학습 및 모델 배포는 완료되지 않았습니다. 학습 전 시각적 근접 중복 제거, 레이블 검수, 동의 재확인, 클래스별 충분한 자료 확보가 필요합니다. 기존 판독기 대비 정확도/오확정률을 독립 평가한 뒤 개선이 검증된 모델만 배포해야 합니다. 내보낸 데이터는 철회 시 삭제해야 하며 학습 직전에도 레코드의 현재 동의를 재확인해야 합니다.
